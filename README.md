## 一、原生IP、广播IP、双ISP住宅IP、独享IP，四个词别混着用

原生IP 指的是这个地址在 ARIN、APNIC 这类注册机构的信息里，归属方就是当地的 ISP 或运营商，而不是某个数据中心的网段。判断方法很直接：拿 MaxMind、IP2Location 查一下，归属显示 Comcast、AT&T、Softbank 这类本地运营商，是原生；显示 Amazon AWS、Cloudflare 或者某家 hosting 公司，就是机房 IP。

广播IP 走的是另一条路。地址段本身不属于当地，商家通过 BGP 路由把它「宣告」成当地地址，数据库里的归属记录要么滞后要么指向数据中心。Google 收录、广告平台风控、流媒体识别都会看这份归属记录，广播IP 在这几处的表现通常差一截。

双ISP住宅IP 是在原生的基础上再叠一层属性：数据库把它识别成住宅宽带，接近真实家庭用户的上网环境。TikTok 跨境运营、广告账户、跨境电商平台这类风控敏感的场景，住宅属性的通过率比商业 IP 高一档，价格也贵一些。

独享IP 讲的是另一件事：这个地址只分配给你一个用户，不与他人共用。它和 IP 归属是两个独立维度。一台机器可以同时是独享 IP 和原生 IP，也可以独享但是机房 IP。

把这四个词记住一个判断顺序就够了：先看归属是不是本地运营商（原生），再看属性是不是住宅（双ISP），最后看是否独享。三个都满足，价格最贵，风控场景也最稳。

「原生IP」这四个字没有统一标准，不同商家的实际含义差得很远。有人租过一台号称原生 IP 的机器，Netflix 一检测直接提示 VPN 或代理节点，页面都打不开。规避办法只有一个：拿到 IP 后自己查一遍归属，别只看商品标题。

## 四、按用途选：五类需求分别看哪个参数

**TikTok 短视频与直播。** 看三样：是否标注「直播无需中转」、上行带宽多少、IP 是住宅还是商业。直播吃上行，100Mbps 和 200Mbps 在实际推流码率上差一档；墨尔本家宽和日本 TK 专用都属于直连档，韩国 SEJONG 则要接受联通绕路。

**账号注册与广告投放。** 这类需求对 IP 属性最敏感，优先双ISP住宅。美国洛杉矶和纽约的双ISP住宅都是 AUD$12.90/月，是这条产品线里价格最低的一档，4837 线路无需中转。

**流媒体解锁。** 住宅属性比商业属性通过率高，但封禁名单是动态的，没有商家能保证长期有效。买之前先想清楚：如果三个月后解锁失效，这台机器还有没有别的用途。

**建站和 SEO。** WePC 不适合。512MB 内存加 10GB 硬盘，跑一个带插件的 WordPress 都吃力，而且官网明确禁止使用 Shadowsocks 协议，说明这类机器的定位是社媒运营而非通用主机。真要建站，同样的预算应该去看配置更高的常规 VPS。

**开发测试。** 够用。需要模拟真实家庭用户 IP 环境的测试场景，住宅 IP 比机房 IP 更接近实际情况。

## 五、下单前必须知道的五条限制

这部分是产品页和条款里写着、但商品列表页看不到的信息，直接影响你会不会白花钱。

**1. 流量超了不停机，限速到 5Mbps。** 韩国原生IP_TK专用的产品页明确写着「5 Mbps speed limit for excess traffic」。这意味着月底流量跑完，机器还在线，但 5Mbps 大概只够发文字和传小图，直播和视频上传基本停摆。其他地区页面没有看到同样的标注，买之前自己确认一句。

**2. 退款是「时间 + 流量」双条件。** 开通 3 天内、且总流量使用不超过 10GB，才可以申请退款。退到账户余额是全额，但余额不能提现；退到原支付方式要扣一笔手续费，第三方整理的口径有 CNY 10 和 AUD 10 两种说法，以结账页条款为准。第 3 天到第 10 天之间，只能退到余额，并且按已使用天数每天扣 6%。超过 10 天不再受理。同一笔订单不能退两次，每天最多 3 笔、每月最多 5 笔，账户充值本身不退。

换句话说，3 天窗口期不是无理由退货期，你得在这 3 天里把 IP 归属查清楚、把目标平台测一遍，且流量别超 10GB。

**3. 禁止使用 Shadowsocks 协议。** 韩国和澳大利亚两个地区页都写了这一条，澳洲页还提示未加中转时用这类协议 IP 掉得快。这类机器是给 TikTok 直播和账号运营设计的，不是给你搭代理的。买来当梯子用，大概率几天内 IP 就废了，而 IP 失效不在退款范围内。

## 七、常见问题

**原生IP 和独享IP 是一回事吗？**
不是。独享说的是这个 IP 只给你一个人用，原生说的是 IP 的归属方是本地运营商。两者互不决定，可以同时具备，也可以只占一个。

**双ISP住宅IP 比原生IP 贵，贵在哪？**
贵在数据库里的属性分类。原生 IP 只保证归属地真实，住宅属性还要被识别成家庭宽带。TikTok、广告平台这类风控会区分这两类，通过率不一样。

**能保证解锁 Netflix 或 TikTok 吗？**
没有商家能保证。平台的封禁名单是动态调整的，今天的测评结论过两个月可能就不成立。比较稳的做法是先买一个月，用退款窗口期测完再决定是否长期用。

**流量用完了会直接停机吗？**
韩国原生IP_TK专用这一款写明超量后限速 5Mbps，不断网。其他地区没有看到同样标注，下单前问清楚是限速还是停机，限速到多少。

**支持支付宝吗？**
支持。支付宝、信用卡、PayPal 都可以，站内以澳元计价，结账时可切换人民币。

**512MB 内存能干什么？**
跑 TikTok 上传、直播推流、账号维护这类轻量任务够用。装面板、跑数据库、建站都不合适，10GB 硬盘也放不下多少东西。
